We want everyone to be able to use this site. We build to the Web Content Accessibility Guidelines (WCAG) 2.2, level AA.

## What we have done

- Text and controls meet the contrast ratios WCAG requires, in light and dark mode. The build checks this.
- Every page works with a keyboard and has a visible focus outline.
- Pages work down to 320 pixels wide and when text is enlarged.
- Forms have labels and plain error messages.
